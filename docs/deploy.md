# Deploy Notes

## Current MVP shape
The application is a static site made of:
- index.html
- styles.css
- app.js

## Fastest publishing options
### Option 1
Publish with GitHub Pages using the repository root.

### Option 2
Deploy to any static hosting provider.

## What works right now
- no build step required
- no backend required
- local persistence in browser storage
- immediate demo availability

## Commercial use
This MVP is suitable for:
- demo calls
- pilot onboarding
- first customer validation
- landing-linked product showcase
